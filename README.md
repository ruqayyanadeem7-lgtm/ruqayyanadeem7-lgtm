# 🐾 Snoopy Booby – Pet Management System

## 📌 Introduction

Snoopy Booby is a Java-based Pet Management System designed to make pet management easier and more organized.

This system helps users manage pet information, keep records of pets being adopted or handed over, and maintain vaccination details. It allows users to store and manage important information about pets in one place.

## ✨ Features

- 🐶 **Pet Management:** Add and manage pet details.
- 🏠 **Pet Adoption:** Maintain records of pets being adopted.
- 🤝 **Pet Handover:** Manage information about pets being given to or received by others.
- 💉 **Vaccination Records:** Maintain pet vaccination details and status.
- 📋 **Pet Information:** Keep important pet records organized.
- ✅ **Status Tracking:** Keep track of completed and pending activities.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## 🎯 Project Objective

The main objective of Snoopy Booby is to provide an organized way to manage pet information, adoption records, handover details, and vaccination history.
